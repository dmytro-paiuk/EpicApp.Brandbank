API keys stay on the server. The browser only calls this app, never connectapi.brandbank.com directly.

GetNext

Returns the next queued batch. Keep calling until you get a 204 — the returned count is approximate and is not a reliable signal that the queue is empty. If the payload comes back truncated or the call times out, this page falls back to GetLast automatically.

1 to 1000. Batching requires the GetLast fallback, which is wired up here.

GetLast

Replays the batch the last GetNext produced. Use it when a payload arrived incomplete.

Product resend

Requeues products already sent that are still in scope. Max 20 per request, one request every 30 seconds. Both limits are enforced here before the call goes out.

Coverage upload

Coverage is the range list. Each upload replaces the previous one, so it must contain every product every time. Max 105MB, and no more than twice a day.

Saved payloads

Every payload is written to disk before anything else touches it. This is not an on-demand service.

Downloaded images

Leased URLs expire after 15 days, so images must be copied into local storage to be usable.
